LeetCode To Github

❓ How to create a GitHub Token
  1. Click here to open GitHub Token settings.
  2. Select "Generate new token (classic)".
  3. Give it a Note name (e.g., "LeetCode Sync").
  4. ⚠️ Important: Check the box for repo (Full control of private repositories).
  5. Scroll down, click Generate token.
  6. Copy the token (starts with ghp_) and paste it above.
